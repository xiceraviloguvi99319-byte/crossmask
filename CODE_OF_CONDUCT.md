# Code of Conduct

CrossMask contributors are expected to communicate respectfully, assume good faith, protect private information, and keep technical disagreements focused on evidence and reproducible behavior.

Harassment, discrimination, threats, doxxing, publication of private data, or misuse of security reports is not acceptable. Project maintainers may remove content or participation that violates these expectations.

Report conduct concerns privately to a maintainer. Do not include sensitive personal data in a public report.
