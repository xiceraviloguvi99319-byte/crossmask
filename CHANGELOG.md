# Changelog

All notable changes to CrossMask will be documented in this file.

## [0.1.0] - 2026-09-19

### Added

- batch processing for CSV and XLSX files;
- deterministic cross-file aliases based on HMAC-SHA-256;
- built-in English and Chinese column rules;
- scan, run, and verify commands;
- Excel privacy report without raw source values;
- synthetic linked-table examples;
- automated unit tests and GitHub Actions workflow.
